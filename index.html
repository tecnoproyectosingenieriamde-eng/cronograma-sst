1 Crear Proyecto en Firebase (Plan Spark Gratuito)

  1. Ingresa a Firebase Console con tu cuenta de Google.
  2. Haz clic en Agregar proyecto. Nómbralo tecnoproyectos-sgsst y continúa (puedes desactivar Google Analytics para agilizar).
  3. En el panel lateral izquierdo, ve a Build (Compilación) > Authentication. Haz clic en Comenzar, selecciona el proveedor Google, habilítalo, introduce el correo de soporte del proyecto y presiona Guardar.
  4. Ve a Build (Compilación) > Firestore Database. Haz clic en Crear base de datos.
  5. Selecciona la ubicación de tu servidor y elige Comenzar en modo de prueba (esto habilitará los permisos de lectura/escritura inmediatamente). Haz clic en Crear.

2 Vincular las Credenciales de Firebase al Código

  1. En la página principal de tu consola de Firebase, haz clic en el icono de engranaje (Configuración del proyecto) al lado de "Descripción general del proyecto".
  2. En la parte inferior de la pestaña General, haz clic en el icono de Web </> para registrar una aplicación. Nómbrala sst-web y haz clic en Registrar app.
  3. Copia el objeto de configuración generado (firebaseConfig) que luce similar a esto: 
    const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
  4. Abre este archivo index.html en un editor de texto bloc de notas o VS Code, busca la línea que dice const firebaseConfig = { ... } (línea ~190) y reemplázala por tus claves reales. ¡Guarda el archivo!

3 Despliegue Gratuito en GitHub Pages

  1. Crea una cuenta gratuita en GitHub si aún no tienes una.
  2. Haz clic en el botón New (Nuevo repositorio). Ponle de nombre cronograma-sst, elígelo como Público y haz clic en Create repository.
  3. En la pantalla que aparece, haz clic en el enlace que dice "uploading an existing file" (subir un archivo existente).
  4. Arrastra tu archivo index.html (ya editado con tus credenciales de Firebase), espera que cargue y haz clic en Commit changes (Confirmar cambios).
  5. Dentro de tu repositorio de GitHub, dirígete a la pestaña de Settings (Configuración) en el menú superior.
  6. En el menú lateral izquierdo, busca la sección Pages.
  7. Bajo Build and deployment, cambia la rama (Branch) de None a main (o master) y haz clic en Save.
  8. Espera de 1 a 2 minutos, recarga la página y verás una barra superior verde que te indicará la URL pública de tu aplicación en internet (ej. https://tu-usuario.github.io/cronograma-sst/).

¡PASO OBLIGATORIO FINAL!

Para que el inicio de sesión funcione en la URL de GitHub Pages, debes volver a Firebase Console > Authentication > pestaña "Dominios autorizados" (abajo del todo), hacer clic en Agregar dominio e ingresar el dominio de tu GitHub Pages sin el "https://" ni subpáginas (ejemplo: tu-usuario.github.io). De lo contrario, Google bloqueará el login.
